## Product scope

### Search

- Origin/destination autocomplete with swap and clear controls
- Browser geolocation (suggest nearby listed stops, on user action only)
- Direct and one-transfer journey search
- Input validation (empty, identical, invalid stops)
- Search normalization (NFKC, case, punctuation, whitespace)
- Alias support (SM, Ayala, and existing aliases)

### Direct journeys

- Route cards with estimated duration, distance, route codes, transfer stop
- Direct/transfer badges, DataStatusBadge (route verification status)
- Route-specific attribution for transfer journeys

### One-transfer journeys

- Transfer stop identification
- Route-specific verification status per route
- Journey steps with ride/transfer breakdown

### Route details

- Full journey steps, assumptions, fare unavailable, data freshness
- Route-specific verification badges

### Map

- Lazy-loaded Leaflet map of listed stop locations
- OpenStreetMap tiles with attribution
- No-geometry notice when route geometry absent
- Marker legend and listed stop locations
- Fit selected stops control

### Saved journeys

- LocalStorage-backed saved journey references
- Reconstruction from current data
- Invalid entry recovery
- Save/remove with accessibility labels

### Themes

- Light and dark themes with persisted preference
- CSS variable-based theming

### Responsive behavior

- Responsive layouts (320-1440px)
- Desktop header nav + mobile bottom nav
- No horizontal overflow
- Touch targets: 44px
