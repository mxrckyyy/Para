# V1.1 Release Candidate - Para

## 1. Release candidate overview

Para V1.1 release candidate. Includes all work through Phase 73: search clarity, data transparency, transfer verification attribution, route evidence upgrades, security hardening, performance optimization, accessibility, cross-browser testing, mobile emulation, and comprehensive documentation.

## 2. Current application capabilities

### Search

- Origin/destination autocomplete with swap and clear controls
- Browser geolocation (suggest nearby listed stops, on user action only)
- Direct and one-transfer journey search
- Input validation (empty, identical, invalid stops)

### Journey discovery

- Journey result cards with estimated duration, distance, route codes, transfer stop
- Direct/transfer badges, DataStatusBadge (route verification status)
- Journey details: steps, assumptions, fare unavailable, data freshness
- Ranking: direct first, then duration, then transfers

### Route transparency

- Verification badges (partially_verified, unverified, etc.)
- Route-specific attribution for transfer journeys (Phase 71)
- Preliminary data notices on results, detail, and map
- Data freshness (lastReviewed date when available)
- Fare and schedule: clearly unavailable

### Map

- Lazy-loaded Leaflet map of listed stop locations
- OpenStreetMap tiles with attribution
- No-geometry notice when route geometry absent
- Marker legend and listed stop locations
- Fit selected stops control

### Saved journeys

- LocalStorage-backed saved journey references
- Reconstruction from current data
- Invalid entry recovery
- Save/remove with accessibility labels

### General UX

- Responsive layouts (320-1440px)
- Light and dark themes with persisted preference
- Desktop header nav + mobile bottom nav
- Not-found page
- Keyboard navigation and focus indicators

## 4. Evidence and verification policy

- Route verification uses a 4-tier model: unverified, partially_verified, verified, outdated.
- partially_verified: some fields supported by credible source, important details unchecked.
- verified: independently checked against identifiable source + field evidence.
- No route is currently verified.
- Estimated durations use straight-line distance at 15 km/h. Clearly labeled.
- Missing data (fare, schedule, geometry) shown as Unavailable, never fabricated.
