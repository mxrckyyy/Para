# Government Records Request Package

## Overview

This directory contains draft records requests for Cebu City and LTFRB institutions. These drafts are NOT submitted. Submission requires explicit authorization from the project owner.

## Request priority order

1. **LTFRB Region VII** (ltfrb-region-vii.md) - Highest priority. Expected to provide route matrix and franchise records.
2. **Cebu City Planning and Development Office** (cebu-city-planning-development-office.md) - Second priority. Expected to provide LPTRP route annexes and maps.
3. **Cebu City Transportation Office** (cebu-city-transportation-office.md) - Third priority. Expected to provide operational route information.
4. **Cebu City Council** (cebu-city-council.md) - Fourth priority. Expected to provide legislative records.

## What each institution is expected to provide

- LTFRB: Route matrix, franchise route descriptions, current status of legacy routes, route amendments.
- CPDO: LPTRP 2024-2028, route annexes, route maps, Notice of Compliance, Mabolo Central Loop documentation.
- CCTO: Current implementation status, operational route information, Mabolo Central Loop status, authorized stops.
- City Council: LPTRP adoption ordinance, amendments to Ordinance No. 2000, supporting annexes.

## Submission tracking

For each request, record:

1. Submission date.
2. Institution.
3. Reference number (if provided).
4. Requested documents.
5. Response deadline (if applicable).
6. Response status (NOT SUBMITTED, SUBMITTED, ACKNOWLEDGED, UNDER REVIEW, PARTIALLY FULFILLED, FULFILLED, DENIED, NO RESPONSE, CLOSED).
7. Received files.
8. Document authenticity assessment.
9. Route evidence extraction.
10. Independent verification.
11. Final classification decision.

## Response handling

- If partially fulfilled: record which documents were received and which were denied or unavailable.
- If denied: document the reason and consider alternative sources.
- If no response: follow up after a reasonable period.
- If fulfilled: verify document authenticity, extract route evidence, and update route verification statuses through a separately authorized implementation phase.

## Important notes

- All requests are drafts. None have been submitted.
- Submission requires explicit authorization.
- Do not submit requests without reviewing the drafts first.
- Preserve all received documents and record their provenance.
